# 02: Run a first recognition demonstration

**What to build:** Give a teammate a simple local command-line demonstration that reads a permitted sample photograph, detects a license plate, prints its text, and saves an annotated image using available pretrained components.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Provide a reproducible Python environment with compatible pinned dependencies and initial setup guidance for macOS, Windows, and Linux.
- [ ] Run recognition locally on an image with a verified source and permitted use; describe how to obtain any required model assets and sample image.
- [ ] Print normalized uppercase text without spaces or separators and save an annotated image; handle multiple plates and no detections.
- [ ] Provide useful errors for invalid input and missing assets, and automated checks of observable command-line behavior without requiring network access or expensive training.
- [ ] Keep the implementation readable and explain the detector and OCR pipeline for a university audience.
